# Apple Pi GitHub 展示资产规范（v1.4.4 方向探索）

## 已核验的产品资产

- 产品名称：Apple Pi（界面中文名「苹果Pi」）。
- 产品类型：Windows 桌面端 AI 编程 Agent；源代码基于开源 Pi Agent，桌面工作区、任务/会话管理、图形界面与工作台由本项目实现。
- 应用标识：`../../../app/renderer/assets/app-icon-rounded.png`。
- 主展示 UI：`assets/apple-pi-full-workflow.png`。该图来自 v1.4.4 的隔离 Electron 实例：无项目绑定、无个人会话、无 API Key、无 OAuth 凭证；画面展示一次「先生成完整执行计划，暂不修改文件」请求的真实计划确认状态。

## 视觉事实

- 产品界面以浅色背景、墨蓝文字与轻量细边框为主体；任务侧栏、对话主区、输入区和计划列表构成完整工作区。
- 产品识别核心不是科技特效，而是「输入请求 → 可见计划 → 待确认执行」的可读工作流。
- 展示画面只可使用真实 UI 截图、真实应用图标与从实际功能抽出的文字；不得重绘、伪造、拼接不存在的产品控件。

## GitHub 展示禁区

- 不在公开图像中出现本机目录、真实项目名称、会话记录、账号、API Key、OAuth Token 或任何个人信息。
- 不使用霓虹数据流、粒子、通用全息 HUD、视频进度条或未经产品证据支持的性能数字。
- 对「一般桌面 Agent」采用类别比较，而不点名第三方产品；比较文案必须限定为常见产品形态，不将其表达成对所有竞品的绝对结论。
