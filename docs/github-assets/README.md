# GitHub 展示素材

本目录保存 Apple Pi GitHub README 使用的公开展示资源。

- `apple-pi-main.png`：1.4.2 版本的隔离实例主界面截图，不包含用户项目、会话或凭证。
- `apple-pi-workbench.png`：1.4.2 版本的隔离实例工作台截图，不包含用户项目、会话或凭证。
- `apple-pi-workflow.html`：README 动画的可审阅 HTML 源文件。
- `apple-pi-workflow.gif`：由 HTML 源文件导出的 README 演示动画。

请勿把真实用户项目、会话、路径、API Key 或本机凭证加入本目录。
