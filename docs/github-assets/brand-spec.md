# Apple Pi GitHub 展示资产规范 · v1.4.4

- **目的**：在 GitHub README 中证明 Apple Pi 的真实桌面工作流，而非制作独立的概念 UI。
- **视觉基调**：暖白背景、细网格、深蓝灰正文、克制的阴影与橙红色微强调；产品截图保持原始深浅与比例。
- **截图来源**：隔离的 Electron 用户数据目录。`apple-pi-main.png` 展示完整任务与已生成的待确认计划；`apple-pi-workbench.png` 展示同一完整窗口里的“智能规划”策略菜单。
- **文本边界**：覆盖层只说明可从实际界面观察到的能力。比较表使用“常见形态”描述，不声称所有其他 Agent 产品都缺少某项功能。
- **动画边界**：镜头仅缩放/平移真实截图；两个状态通过真实截图交叉淡入。最终 MP4 保留 BGM/SFX，GIF 静音并使用调色板优化。
- **隐私**：不使用用户工作区、真实项目路径、凭证或会话内容；截图内全部为演示任务。
