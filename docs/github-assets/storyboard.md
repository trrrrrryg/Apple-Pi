# Apple Pi GitHub 流程演示 · v1.4.4

用途：README 顶部的产品工作流演示。所有屏幕均来自隔离运行实例；镜头、描边和文字只用于引导真实界面中的信息，不重绘或伪造产品界面。

规格：1920×1080、15 秒、25fps H.264 MP4；从该 MP4 派生 800×450、10fps 的调色板优化 GIF，以保证 GitHub README 的加载体积和可读性平衡。MP4 使用低干扰的 tutorial BGM，并在三个核心视觉节点加入软点击/生成完成/收束音效；GIF 保持静音。

验收规则：

- 第 0 帧和最后一帧都是完整布局，不能是加载页、黑帧或下一轮循环。
- 同一时间只有一个真实界面区域被强调；没有仿制窗口、进度条或播放器控件。
- `apple-pi-main.png` 与 `apple-pi-workbench.png` 均为隔离实例截图，不含项目文件、凭证、真实会话或个人目录。
- 动画含 `Created by Huashu-Design` 水印；README 直接嵌入静音 GIF，并提供带音轨的 MP4 下载链接。
