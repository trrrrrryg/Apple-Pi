关键问题Apple Pi一般桌面 Agent 常见形态
任务如何被组织？项目、会话与任务列表在同一桌面工作区。以单个对话或一次临时任务为中心。
复杂任务如何起步？计划策略独立于执行权限，可先生成、细化并确认计划。计划常依赖模型临场决定，执行与规划容易混在一起。
工具如何被看见？Git 改动、浏览器、终端与对话保持在当前项目语境。工具或上下文常分散在外部窗口与命令行。
模型与扩展如何接入？内置/自定义兼容模型、本地运行时、MCP 与 Skill 可统一管理。模型、插件和本地运行时的入口常各自分散。
